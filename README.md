# Azure Serverless Cloud Resume

## Overview
A serverless cloud resume website demonstrating Microsoft Azure, Terraform, Python, and DevOps practices.

## Planned Architecture
- Frontend: HTML, CSS, JavaScript, Tailwind CSS
- Hosting: Azure Static Web Apps
- Backend API: Azure Functions (Python HTTP trigger)
- Database: Azure Cosmos DB for NoSQL
- Infrastructure as Code: Terraform
- CI/CD: GitHub Actions
- Monitoring: Azure Monitor and Application Insights

## Project Structure
- `frontend/` — Resume website
- `backend/` — Python visitor counter API
- `terraform/` — Azure infrastructure configuration

## Project Status
In development — Azure environment verified; infrastructure not yet deployed.

## Security Goals
- Least-privilege Azure RBAC permissions
- Managed identities where supported
- No credentials committed to Git
- Secure GitHub Actions authentication using OIDC where supported
